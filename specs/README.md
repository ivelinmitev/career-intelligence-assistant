# Specs

This repo uses spec-driven development (Spec Kit style).

| Path | Role |
|------|------|
| `.specify/memory/constitution.md` | Non-negotiable principles |
| `specs/001-career-intelligence-assistant/` | Current product spec, plan, contracts, tasks |
| `AGENTS.md` | How agents work in this repo |

## Add a feature

1. Copy the next number: `specs/002-short-name/`.
2. Write `spec.md` (what/why). Then `plan.md` (how). Then `tasks.md`.
3. Implement tasks in order. Check them off.
4. Run `npm test`.

Use the `add-feature-spec` and `implement-from-spec` project skills.
